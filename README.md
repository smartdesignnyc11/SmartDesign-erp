# SmartDesigns Projects ERP

The single-file ERP for SmartDesign NYC / Mercer & Bond (design-build, landmark brownstones).

    python3 build.py                 # -> dist/smartdesigns_projects.html (open it in a browser)
    cd tests && python3 smoke_test.py && python3 baseline_test.py

Requirements: Python 3.10+, Node 18+, `pip install playwright && python3 -m playwright install chromium`.

Start with CLAUDE.md, then HANDOFF.md, docs/BACKLOG.md, docs/ARCHITECTURE.md and docs/REVIEW_PROTOCOL.md.
docs/reference/ holds the earlier specs (system brief, accounting spec, style, mobile, field).
