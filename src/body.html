How the schedule logic works

Dates are working days: Monday–Friday, minus holidays. A task can be marked to allow weekend work.

Critical path is recalculated on every change from task dependencies. Zero-float tasks show a red edge; every day lost on them moves the finish.

A material's need-by date is its task's start minus the material buffer. Its order-by date is need-by minus lead time. Both move automatically when the task moves.

An inspection gates the task chosen for it. If it is not passed before that task's start it is flagged; if it is not scheduled within the inspection buffer, you are told to book it.
