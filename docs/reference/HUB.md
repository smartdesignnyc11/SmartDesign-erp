# Sales Hub — the Sales group rebuilt on HubSpot's model (2026-09-13)

Modules `erp/hub_core.js` (objects, properties, index pages, create panel), `erp/hub_record.js` (record page, composers, tasks panel), `erp/hub_tools.js` (Tasks, Sequences, Sales Workspace, Quotes, Forecast, Dashboard, Playbooks, Settings, nav, seed) · tests `erp/hub_test.py` (52 checks) · CSS in `ia.css` (`.hb-*`). The previous Sales module (`sales.js`, `funnel.js`) stays underneath: the deal record IS the lead, the next-best-action rules and the building card come along, and the classic Pipeline is one click away from any deal.

## What HubSpot has, and what is here
Nav — Sales group tabs: **Workspace · Deals · Contacts · Companies · Tasks · Sequences · Quotes · Forecast · Dashboard · Playbooks · Partners · Numbers · Settings**.

**Objects.** Contacts (first/last name, email, phone, mobile, job title, company name, owner, **lifecycle stage** Subscriber→Lead→MQL→SQL→Opportunity→Customer→Evangelist→Other, **lead status** New/Open/In progress/Open deal/Unqualified/Attempted to contact/Connected/Bad timing, **buying role**, city, address, persona, create/last activity dates, times contacted, original source), Companies (name, domain, website, industry, type, owner, lifecycle, lead status, employees, phone, address, city, state, zip, description, target account), Deals (deal name, amount, pipeline, **deal stage**, close date, owner, deal type New/Existing Business, priority Low/Medium/High, **forecast category** Not forecasted/Pipeline/Best case/Commit/Closed won, forecast probability and amount, deal probability from the stage, **weighted amount**, next step, description, closed won/lost reason, last activity, next activity, times contacted, create date, time in current stage, deal source, plus SmartDesign's property, building, scope and lead score). Associations with labels (Decision maker, Budget holder, Executive sponsor, Legal & compliance, Champion, Influencer, Architect, Broker, Board / managing agent, Lender; company Primary). Activities: notes, emails, calls (outcome Busy/Connected/Left live message/Left voicemail/No answer/Wrong number, direction, duration), meetings (outcome Scheduled/Completed/Rescheduled/No show/Canceled, type), tasks (To-do/Call/Email/LinkedIn; None/Low/Medium/High; queue; reminder; repeat). Quotes = the estimates; line items and a product library.

**Pipeline** (Settings › Pipelines): stages with **deal probability** (Inquiry 10 · Qualified 25 · Site visit 40 · Design agreement 60 · Proposal out 80 · Closed won 100 · Closed lost 0), Won/Lost flags, drag to reorder, **+ Add stage**, **Update stage properties** per stage with required properties — a move into Design agreement needs an amount, into Proposal out an amount and a close date, into Closed lost a reason; the "Update stage properties" modal blocks the drop until they are filled. Changing a probability changes every weighted amount.

**Index pages** (Deals, Contacts, Companies): header with record count, **Actions ▾** (Edit properties, Manage views, Export, Import), **Import** (CSV mapped by property label), the orange **Create**; **saved views as tabs** (All / My / + Add view; rename, clone, set as default, save filters and columns to the view, delete; All views); the filter bar with the **quick-filter pills** (Deals: Deal owner, Create date, Last activity date, Close date; Contacts and Companies: owner, Create date, Last activity date, Lead status), **+ More**, **Advanced filters (n)** in a right panel (property → operator → value, AND), **Clear all**, search, **Edit columns** (property picker + draggable selected list), Export; **Board / Table** toggle for deals; table with sortable headers and the column ⋮ menu (sort asc/desc, filter by this column, move left/right, remove), checkboxes, the hover **Preview** button and preview side panel, double-click cell edit, pagination with 25/50/100 per page; the **bulk bar** (N selected · Assign · Edit · Enroll in sequence · Create tasks · Export · Delete with typed-count confirmation · Select all N). **Board**: a column per stage with count, **Total** and **Weighted**, cards with amount, close date, owner avatar, priority flag, last activity and the 14-day stale dot, **drag-and-drop** between stages (required-property modal on drop), card click → preview, Board options to choose the four card properties.

**Record page**: three columns. Middle — the **deal stage tracker** (chevrons; click to move; Closed lost asks for the reason), **Overview** (data highlights Create date · Close date · Deal stage · Last activity date; Recent activities; next best actions; associations summary) and **Activities** (sub-tabs Activity · Notes · Emails · Calls · Tasks · Meetings; search; Filter activity; All users; Create note / Log activity / Create task; **Upcoming** then month groups; collapsible items). Right — association cards with **+ Add** (add existing with association label, or create new): Contacts, Companies, Quotes, Line items (from the product library into the proposal), Attachments, Playbooks; on contacts Companies (Primary), Deals, Attachments, Sequences. Composers dock bottom-right for Note / Email / Log call / Log meeting; Task opens the right panel with Title, Type, Priority, Associate with records, Queue (Create new queue…), Assigned to, Due date and time, Task reminders, Notes, Set to repeat, Create / Create and add another.

**Tasks**: tabs All · Due today · Overdue · Upcoming · Completed with counts; quick filters Assignee, Task type, Due date, Queue, Priority; the status circle; Manage queues; **Start N tasks** opens each record with the Task 1 of N · Complete · Skip bar. **Sequences**: index with enrolled, active, reply rate, meeting rate; editor with step list (Automated email, Manual email task, Call task, General task, LinkedIn task), business-day delays, personalization tokens, Settings (send window, business days, skip weekends), Automation (unenroll on reply / meeting / same company); ## The check
A HubSpot power-user review walked every page against Sales Hub and came back with a list; all of it is in. Bugs: panel titles and buttons rendered invisible outside the Sales views (the `--hb-*` colours lived on `.hb-view`; moved to `:root`), the deal name showed `&amp;` (double-escaped), the funnel could go up between stages (now counts the furthest stage reached), forecast periods mishandled closed deals and lost ones inflated the pipeline, the dashboard's Deal forecast ignored the date range, a stage change counted as an activity, contacts and companies showed no activity (they now roll up their deals'), property history was empty (`hbSet` records every change; History shows it with the stage changes), checkboxes and radios overflowed their rows, dropdown menus stayed open after a pick, quotes showed no status or owner, modals opened from a side panel were unclickable (z-index), the seed died on a null lead so playbooks never seeded. Fidelity: Closed won via the tracker now asks to confirm, sets the close date to today and the forecast category to Closed won, and stays on the record; advanced-filter values are typed (a stage picker, a user picker, dates, numbers, yes/no); Board options is a real dropdown (Edit cards / Sort by amount / Sort by close date / Hide empty stages) and the view and column menus float inline; the action row uses line icons; the record header's amount, close date and stage edit inline; timeline items are titled (Call with Priya Raman · by Owner) with an Overdue group above Upcoming; the email composer has From/To/Cc/Bcc and Templates/Snippets/Documents/Meetings inserts; log-call has outcome, direction, date, time, duration, associated records and a follow-up task; Workspace › Leads excludes customers and contacts on closed deals; the sequence editor has an Enrollments tab; the pipeline editor lets you set which stage is Won/Lost and separates *shown* from *required* stage properties; modal primary buttons are HubSpot orange inside the Sales views; priorities are seeded so the board shows flags. Still to do from the review: full-page quote wizard, step preview in the Enroll modal, a card ⋮ menu, frozen name column, dashboard drag/resize, Tickets, workflows, report builder.

52 automated checks (`hub_test.py`) and the full regression (86 suites) pass.
